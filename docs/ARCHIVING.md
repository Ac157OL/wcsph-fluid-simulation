# 整理与隐私检查记录

## 版本与范围

以原项目的 `warpTest_physical_clean` 为主版本，保留其模拟和渲染源码以及依赖文件。未合并旧版本中额外的阻尼逻辑、任务验收或报告生成脚本。核心算法未修改。

仅保留一个 ASCII PLY 示例点云，包含顶点坐标，不包含图像、作者字段或本地路径。README 已改写为独立项目说明，不再依赖原始任务书或提交材料。

## 本地归档

全部原始文件移至项目之外的私有归档，包括三个版本、文档、论文、提交包、缓存和模拟结果。归档父目录权限设为仅所有者可访问。归档保存文件清单及 SHA-256 校验值，移动后逐文件复核内容一致。私有归档不是脱敏产物，不应上传。

发布目录中不包含原始 Word/PDF、Blender 工程和 ZIP，避免携带未经审查的文档元数据、嵌入资源或历史文件。原项目没有 `.git`，整理后的目录也不携带旧提交历史。

## 上传前检查

运行 `python scripts/check_privacy.py`。检查器扫描项目内所有文件（包含被 Git 忽略的文件），跳过 Git 内部数据、虚拟环境和 Python 缓存。它仅接受源码、Markdown、依赖清单和指定示例点云，并检查常见凭据、联系方式及个人目录路径。未知文件类型和符号链接会要求人工处理，输出不回显敏感内容。

若运行模拟后检查器报告生成文件，请将结果移到仓库目录之外，再检查准备上传的目录。`.gitignore` 只约束 Git，不约束网页上传或手工压缩目录。

检查器不检查 Git 历史、Git 提交作者或远端内容，也不能识别全部个人信息。首次提交时应检查作者配置与暂存文件。当前整理未创建提交、远程仓库或上传内容。

## 验证边界

整理时核对了保留源码与主版本的一致性，进行了 Python 语法、示例点云结构、隐私扫描和忽略规则检查。整理环境未安装仿真依赖，因此未重新运行 GPU/CPU 仿真或 Blender 渲染；原有长期模拟结果不作为本次重新验证的结果。
